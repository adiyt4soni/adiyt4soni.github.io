Job-search and LinkedIn outreach system

My own job search, run as one system: it screens about 415 company job boards against rules I wrote, builds a tested CV for each role that passes, and runs LinkedIn outreach for the same roles automatically.

My part: I wrote the rules, asked for the audit, decided what changed, and nothing is submitted until I say 'apply'. Claude Code wrote the tools; Codex wrote and reviewed some of the prompts.

How I work with AI

The same loop runs through every project. Examples for each step →

  1. Define the problemWrite down what the system must do and what it must never do, before any code.
  2. Set constraintsPrivacy, cost and approval rules go into code where they can be tested, not into a prompt.
  3. Choose toolsPick the model, library or existing skill that fits, and record why.
  4. DelegateHand a written specification to Claude Code; keep each task small enough to review.
  5. ReviewA second model (Codex) reviews the change read-only; I decide which findings to act on.
  6. Test against evidencePre-registered checks, baselines and spot-checks against the source data.
  7. CorrectWhen a check fails, fix the cause and add a check so it can't recur.
  8. Accept or stopShip what passed; report nulls and stop what didn't earn its place.
